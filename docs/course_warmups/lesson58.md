    !!! info "🌍 Sound Connections"
        Tale means cross, through, like Welsh taith (journey, passage).  
        Paro means front. It comes from Latin pro/prae and Romance para, meaning in front, toward.
      
    Here are other words with these roots:    
    **boetale** = hall (house spaces + cross), just like jentale = through (geometrics and location + cross)   
    **varparo** = face (face + front), just like jenparo = front (geometrics and location + front)
   
    This cluster has two important words, *jetai* and *jenon*.  
    
    *Jetai* means *direction*, and is used to specify the direction of movement. Compare:
    
    ```
    i vanvu en leayo = I run in the park  
    i vanvu jetai leayo = I run towards the park  
    ```
    
    *Jenon* means *path, way*. If you use its root in front of a word, you indicate this word as an explicit adverb. Take a look:  
    
    ```
    i vanvu yasoi = I run fast  
    i vanvu non yasoi = I run fast (way: fast)  
    ```
    
    This use is an option for when a sentence may be ambiguous otherwise. Notice you may also use a hyphenated expression here:
    
    ```
    i yasoi-vanvu = I run fast (fast-run)
    ```

=== "Reading"
    
    Now that you know quite a bit, let's take a look at some general discourse guidelines. These are important for communicating fluidly and preventing ambiguity. During the course, you may have noticed a few of these things, or developed an intuition for them. Now we will explore them explicitly, but don't worry about memorizing. 
    
    ## 1. Dropping pronouns and subjects
    
    Oravia omits possessives when ownership is obvious: body parts, family roles, clothing, body actions.
    
    ```
    farejor i anifi    = mother is coming (not: my mother)
    i siur e yesrel    = remove the jacket (not: your jacket)
    ```
    
    Many utterances don't have a subject. In this case, an affirmative sentence defaults to *I*, and a question defaults to *you*:
    
    ```
    i ilianum   = [V] know-not = I don't know
    ce i anye?  = what [V] do? = what are you doing?
    ```
    
    In longer sentences or narratives, when a subject is introduced, it becomes the subject until another one is made explicit. If the subject changes, you must introduce it. This is true even if you would normally not use *I* or *you*:
    
    ```
    Haya i ilian e ca i anye     = they know what [they] are doing
    Haya i ilian e ca nim i anye = they know what I am doing
    ```
    
    ## 2. Sentence structure
    
    Once a subject is active in discourse, you can use a reduced expression referring back to that subject. This is the full explicit way of saying someone is something:
    
    ```
    A Lina a roena dia. A hay a toului.
    = Lina is a teacher. She is tired.
    ```
    
    But since Lina is already the active subject, you don't have to repeat the full structure. You may say instead predicate + pronoun, or even only the predicate:
    
    ```
    A Lina a roena dia. Toului hay.

    A Lina a roena dia. Toului.
    = Lina is a teacher. [She is] tired.
    ```
    
    Another way you may change sentence structure is through moving the order around. To do this, you just need to keep in mind that a marker and all the words it introduces form a block. Each block moves as a unit and should not have its contents split.
    
    ```
    nim   i copei   en yamirli bo   en mir lidastor
    = I searched in my old house for many years
    ```
    
    Example of valid orders:
    
    ```
    [en yamirli bo] [nim] [i copei] [en mir lidastor]
    [nim] [en yamirli bo] [i copei] [en mir lidastor]
    ```
    
    This is NOT valid because it breaks a block:
    
    ```
    ❌ [nim] en [i copei] nim yamirli bo   (en split from its block)
    ```
    
    ## 3. Dropping markers
    
    If you have a clear unmarked block, that block defaults to the subject. Because of this, the *a* marker is dropped most easily:
    
    ```
    a miau i bortal = miau i bortal = the cat enters
    a miau e muvardur i copei = miau e muvardur i copei = the cat hunts the mouse
    ```
    
    The *e* marker drops when the object is unambiguous. The *u* marker is rarely dropped.
    
    Dropping markers and words makes the sentence less formal. Besides this, using roots and short forms also makes a sentence less formal. For example:
    
    a nim i dapas i mo -> formal
    i pas i mo -> casual

    async function initReview() {
    const wrongIds = JSON.parse(localStorage.getItem('wrong_ids') || '[]');
    const container = document.getElementById('review-game-container');
    if (!container) return;
    if (wrongIds.length === 0) {
        container.innerHTML = '<div style="text-align: center; padding: 3rem; background: #e0f2f1; border-radius: 8px;"><p style="font-size: 1.2rem; color: #4a9cd6; margin: 0;">🎉 No words to review!</p><p style="color: #5a8bb8; margin-top: 0.5rem;">You did not miss any words. Excellent work!</p></div>';
        return;
}
    try {
        const lessonIds = [...new Set(
            [...document.querySelectorAll('[data-lesson]')]
                .map(el => el.dataset.lesson)
        )];
        const baseUrl = window.location.origin;
        const responses = await Promise.all(
            lessonIds.map(id => fetch(baseUrl + '/data/' + id + '_words.json').then(r => r.json()))
        );
        const allWords = responses.flatMap(data => data.words);
        const seen = new Set();
        const uniqueWords = allWords.filter(w => {
            if (seen.has(w.id)) return false;
            seen.add(w.id);
            return true;
        });
        const wrongWords = uniqueWords.filter(word => wrongIds.includes(word.id));
        if (wrongWords.length === 0) {
            container.innerHTML = '<div style="text-align: center; padding: 3rem; background: #e0f2f1; border-radius: 8px;"><p style="font-size: 1.2rem; color: #4a9cd6; margin: 0;">🎉 No words to review!</p></div>';
            return;
        }
        container.innerHTML = '<p style="text-align: center; margin-bottom: 2rem; color: #5a8bb8;">Practice these ' + wrongWords.length + ' word(s) you found challenging:</p><div id="review-game-wrapper"></div><div style="text-align: center; margin-top: 2rem;"><button id="clear-review" style="padding: 0.5rem 1.5rem; background: #f57c00; color: white; border: none; border-radius: 4px; cursor: pointer; font-size: 0.95rem;">Clear Review List</button></div>';
        new MatchingGame('review-game-wrapper', wrongWords, 'review', null, []);
        document.getElementById('clear-review').addEventListener('click', function() {
            if (confirm('Clear all review words? This will reset your wrong words list for this lesson.')) {
                const allWrongIds = JSON.parse(localStorage.getItem('wrong_ids') || '[]');
                const lessonWordIds = uniqueWords.map(w => w.id);
                const remainingWrongIds = allWrongIds.filter(id => !lessonWordIds.includes(id));
                localStorage.setItem('wrong_ids', JSON.stringify(remainingWrongIds));
                location.reload();
            }
        });
} catch (error) {
        console.error('Error loading words:', error);
        container.innerHTML = '<p style="color: #f44336;">Error loading review words. Please refresh the page.</p>';
}
}
document.addEventListener('DOMContentLoaded', initReview);
