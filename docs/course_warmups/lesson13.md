    There is a very useful particle for adjectives: **ho**.
    We use it in front of a word to indicate its **opposite** meaning. For example:
    
    ```
    a nim a yalen = I am tall
    a nim a ho yalen = I am short
    ```
    
    We can use *ho* in front of many kinds of words, not only adjectives! For example:
    
    ```
    nim i bonfene = I lie down
    nim i ho bonfene = I stand up
    ```
    
    Notice that it is not the same as the negative -um:
    
    ```
    nim i ho bonfene = I stand up
    nim i bonfeneum = I don't lie down
    ```
    
    Now try to create a sentence using *a...a...* and *ho*, or 3 if you're up for a challenge!
