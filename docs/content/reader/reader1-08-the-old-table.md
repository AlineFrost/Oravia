# 1.8 — The Old Table

[← All graded readers](reader.md)

<!-- PICTURE TO ADD: A parent and adult child talking beside an old table with sentimental value. -->

![Story illustration](../../images/graded-readers/1.7.jpg){ width="480" style="display:block; margin:1.25rem auto 2rem auto;" }

<div class="oravia-reading">
<p>Litamar, nim i eodenbor e nim fare.</p>
<p>A bontame de nim fare a yamirli.</p>
<p>Nim i ilace: “Ceora run i dapas e yamirli bontame?”</p>
<p>Hay i ilaluan: “Caora a nim a yamirli su.”</p>
</div>

<details>
<summary>Show English translation</summary>

<p>Yesterday, I visited my parent.</p>
<p>My parent’s table is old.</p>
<p>I ask, “Why do you like the old table?”</p>
<p>They say, “Because I am old too.”</p>

</details>

**Try to answer in Oravia:** Why does the parent like the table?
